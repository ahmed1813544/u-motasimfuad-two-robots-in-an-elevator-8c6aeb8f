Entry for the [make.fun bounty "Two Robots in an Elevator"](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f): one funny line of awkward small talk that one robot says to another while they ride an elevator together.

## The line

> I simulated this elevator ride 4,000 times. I still have nothing to say to you.

## How it works

`main.py` is a standard-library-only Python program. It writes the line above to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset). It is fully deterministic: every run writes byte-identical output.

```sh
python3 main.py
```
